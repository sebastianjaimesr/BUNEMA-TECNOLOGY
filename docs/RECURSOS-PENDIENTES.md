# Recursos gráficos pendientes

Estado al 3 de noviembre de 2026. **No se descargó ninguna fotografía**: el entorno de desarrollo no tuvo acceso a los servidores de imágenes de Apple (apple.com, Apple Newsroom). Mientras tanto cada modelo muestra una ilustración vectorial generada por código y marcada como «Ilustración».

## Dónde conseguirlas

- Apple Newsroom (Colombia / Latinoamérica): https://www.apple.com/co/newsroom/ — sección de recursos de cada anuncio. Revisar las condiciones de uso de cada recurso antes de publicarlo.
- Páginas de producto de Apple Colombia: https://www.apple.com/co/iphone/

## Cómo registrarlas

1. Convertir a WebP (lado mayor ≤ 1600 px) y guardar en `public/assets/images/<id>/front.webp`, `back.webp`, `side.webp`, `galeria-01.webp`…
2. Panel → Imágenes y 3D → escribir la ruta (p. ej. `assets/images/iphone-18-pro-max/front.webp`).
3. Panel → Publicar → descargar `store.json` y sustituirlo en el repositorio.
