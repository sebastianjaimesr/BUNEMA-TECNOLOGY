# Modelos 3D

Archivos `.glb` optimizados (Draco/meshopt, texturas ≤ 2048 px, < 3 MB) nombrados por `id` de modelo,
p. ej. `iphone-18-pro-max.glb`. Se registran en el panel (Imágenes y 3D → Modelo 3D). El visor los escala a las
medidas oficiales; si un archivo falta o falla, se usa el modelo generado por código.
